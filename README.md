# GitLab Radar

GitLab Radar собирает сведения о GitLab-проектах и показывает технологии, зависимости,
контейнерные образы, CI-компоненты, webhook и соответствие требованиям компании.
Поддерживаются Python, Java и JavaScript/TypeScript.

Каталоги доступны без входа. Управление использует OIDC; администратор запускает сканирование вручную и может его остановить.
Обращения к GitLab выполняются последовательно, готовые результаты появляются в интерфейсе по мере обработки.

## Запуск

Подготовьте `.env` по [примеру](.env.example) и настройте внешний OIDC-провайдер
по [инструкции запуска](docs/deployment.md).

```shell
docker compose up -d --build
```

Приложение доступно по адресу `http://127.0.0.1:8000`.
