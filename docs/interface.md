# Интерфейс и управление

## Каталоги

| Экран | Назначение |
|---|---|
| Обзор | Сводка языков, технологий, версий, качества данных и соответствия требованиям |
| Проекты | Поиск и фильтрация, модули, зависимости, диагностика и экспорт выбранных данных в XLSX |
| Зависимости | Версии пакетов и проекты использования; фильтры языков и транзитивных зависимостей |
| Образы | Registry, пути образов, версии и проекты использования |
| CI-компоненты | Компоненты GitLab CI, версии и проекты использования |
| Webhook | Домены, безопасные ссылки и проекты использования |

Образы, CI и webhook используют общий экран каталога с деревом и подробностями выбранного элемента.
Выбор технологии или нарушения в обзоре переводит к соответствующим проектам либо зависимостям.
Актуальность данных и качество анализа отображаются отдельно: [значение статусов](scanning.md).

## Администрирование

| Раздел | Действия |
|---|---|
| Сканирование | Кнопка «Запустить сканирование» меняется на «Остановить» во время запуска; текущий этап, прогресс, счетчик запросов и ошибки |
| Языки программирования | Включение анализаторов, минимальные актуальные версии, настройка фреймворков |
| Требования компании | Создание групп и требований, включение, редактирование условий и порядка |
| Параметры | Срок хранения опубликованных сканирований и пороги отображения соответствия |
| Пользователи | Назначение администратора, блокировка, добавление и удаление локальной записи |
| Видимость | Личные группы, административные политики и индивидуальные правила |
| Черный список | Полные пути и glob-шаблоны проектов, исключаемых из сбора и каталогов |

Роли и особенности публичного доступа: [авторизация](access.md).

## Требования компании

У требования есть код, название, группа, необязательная привязка к языку и дерево условий `AND`/`OR`.
Условия могут проверять runtime, пакетный менеджер, прямые и опциональные зависимости, инструменты,
CI-компоненты, безопасные webhook URL, registry и набор языков. Транзитивные зависимости не участвуют
в проверке наличия прямой зависимости.

Поведение при отсутствии значения задается условием. Языковые требования применяются к соответствующим
модулям, глобальные — на уровне проекта. Результаты и проценты соответствия пересчитываются при чтении
по текущим настройкам: это не историческая оценка правил на момент старого сканирования.

## Языки и фреймворки

Включенный язык участвует в выборе файлов и анализе при следующем запуске; выключенный продолжает
учитываться в статистике языков. Новый язык включается автоматически при наличии анализатора.
Java и JS/TS изначально выключены; настройки JavaScript и TypeScript изменяются совместно.

Фреймворк определяется по прямым, опциональным зависимостям и инструментам, если включены он и его язык.
Транзитивная зависимость сама по себе не определяет фреймворк. FastAPI подавляет Starlette,
а Next.js — React внутри одного модуля.

Минимальная актуальная версия задается для языка. Пустое значение означает отсутствие ограничения;
исходные значения для Java — 8, для JS/TS (Node.js) — 22.
